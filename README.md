# NCVET validation and cleaning tool

Run `python -m streamlit run streamlit_app.py`, or use `START_TOOL.cmd` on Windows.
Upload a new link workbook, select its reporting month/year, and run validation
and cleaning. Outputs include submission status, consolidated data and cleaned
data with an audit trail. Scoring and grading are no longer part of the app or
pipeline.

See [DEPLOYMENT.md](DEPLOYMENT.md) for free Streamlit Community Cloud hosting and
local setup. `NCVET_Cleaning_Tool.zip` contains the deployment files without old
submissions, reports or scoring modules.
